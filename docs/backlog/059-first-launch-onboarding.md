## Problem

On an empty garden the dashboard says "Votre jardin se porte bien" and shows
empty sections. Nothing tells a new user what to do first.

## Why it matters

The first minutes decide whether the app gets used. A wrong reassuring message
and a blank screen lose the user before the first plant.

## Acceptance criteria

- [ ] With no plant, the dashboard shows a short guided start: create a zone,
      add a plant (with search), take its first photo — each step checked off
      as done
- [ ] The hero subtitle never says the garden is fine when it is empty
- [ ] The guided start disappears once the garden has a plant with a photo, and
      can be dismissed
- [ ] Offers "Importer une sauvegarde" for users coming from another device (020)
